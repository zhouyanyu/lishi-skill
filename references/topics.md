# 纪事本末与历史专题

## 事件页与大事记

大事记是按时间进入事件的索引，保留时间精度、地点、事件简述及页面链接；信息不足的先后并列或写不确定，不制造完整年月日。

事件页采用纪事本末：

1. 事件界定、时间地区、参与者及一句话说明。
2. 前因：长期条件、具体矛盾、直接触发及解释分歧。
3. 经过：按实际时间列阶段、行动、响应、转折，注明来源。
4. 结果与后续：短期结果、后续变化；后世影响有依据和适用范围。
5. 记载对照与证据：本纪、列传、志、表和其他资料分别提供什么。
6. 相关人物、制度、地理、文化，Mermaid 图和待查事项。

记载对照建议表：`来源及层次｜实际说法与锚点｜互补／重复／独立佐证／冲突｜判断与限制`。是否独立不知道时标明，不按材料条数投票。不为每条日常任命另建事件页；可纳入任职表，复杂或重要事件才独立。跨章同一事件归入同页，事件范围不同但有关联时连接而非强并。

## 战争与战役

明确战争与单次战役的层级，记录目标、参战势力、指挥关系、兵源装备、动员财政、兵力伤亡口径、集结部署、行动阶段、补给交通、地形季节、胜负与政治社会后果。来源缺项留缺项。

Mermaid 分别画指挥关系、阶段进程或行动路线示意。路线依据实际移动；战场几何、距离、高程须用有依据的地图，Mermaid 不充当真实地形图。因果图注明作者解释／综合推断。

## 人物与政权群体

人物页保留身份别名、家世、分期生平、任职表、重要行动与主张、关系变化、文化活动、评价分歧、来源。关系图限定有效时期，亲属、同僚、统属、联盟和对立不混标。史书的文学化言行须说明依据。

政权、宗族、地方势力、族群及宗教组织按实际材料建页，记录形成与变化、组织、活动区域、主要成员、对外关系。避免把复杂群体当成永远统一行动的主体。

## 制度与地理

制度页记录时代地区、定义术语、规范来源、结构职责、办理过程、选任考核、实际案例、沿革与争议。正式规定、例外、地方实践分开；同名跨朝制度不直接合并，综合页可比较。

地理页记录古地名和异名、适用时间、行政沿革、现代对应及确定度、自然地理、交通经济军事作用、文化环境、相关事件和来源。区域、水系、道路和关隘都可建档；河道海岸变化及古路线不能凭现代地图补写。

## 文化重点整理

文化与制度共同构成默认核心，不只对政治战争提供解释。志中的文化条目详细整理，列传、本纪、注释和学术著作的文化材料同步汇入。根据真实内容建页，不机械建立全部空目录。

| 领域 | 关注信息 |
|---|---|
| 礼仪祭祀 | 场合、主体、程序、空间、祭品、对象、象征与变迁 |
| 音乐艺术 | 乐制、乐器、曲舞、表演者、使用场合、审美与传播 |
| 舆服仪卫器物 | 形制材料、颜色数量、身份限制、车舆仪仗、制造与使用 |
| 婚丧节令与生活 | 仪式程序、家庭社会关系、饮食居住、地方与群体差异 |
| 宗教思想 | 信仰、仪式、组织、观念、人物、社会作用及争议 |
| 教育艺文知识 | 学校取士、书籍分类、学术群体、知识传播、技术与实践 |
| 历法天文与灾异 | 计时规则、观测、现象、当时解释、仪式政治关联 |
| 地方与群体文化 | 地区、阶层、职业或族群背景，交流、差异与变化 |

文化页的主体是**是什么、谁使用、何时何地、怎样进行、意味着什么、如何变化**。器物、服饰、程序与分类保留具体信息，用表格承载密集数据，用 Mermaid 展示流程、层级或演变。

区分官方礼制、作者主张、实际事例和广泛习惯；单个事例不能代表全体。象征意义来自当时解释或研究，现代推断注明。看似细小但对文化理解有价值的信息不能因不是重大事件而省略。

## 来源问答

先界定问题：问本书如何记载，还是综合历史解释。检索已有索引与页，再回查直接支持的原文；缺相关材料时说明。

默认答复：直接结论 → 关键依据和可点击定位 → 必要背景／分歧与不确定性。需要多个步骤才能解释时增加图表。区分书内信息和实际查证的外部补充，不声称读过仅见于转引的原书。跨书合并时保持版本与来源层次。
