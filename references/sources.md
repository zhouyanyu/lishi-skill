# 原文提取、来源与稳定定位

## 确定阅读单元

读取版本信息、实际目录和正文标题，保存完整单元清单。正史保留卷、篇、本纪、志、表、列传和附注层次；一个卷含多篇时可分篇，但记录所属卷。不把 EPUB 的每个 HTML、PDF 的每页或扫描目录项直接当成一章。

EPUB 按 `META-INF/container.xml` 找 OPF，读取 metadata、manifest、spine，结合导航／NCX 与实际标题确认顺序。跨 HTML 的同一篇合并，同一 HTML 的多篇按有依据的标题拆分，记录内部文件与原锚点。不要按 ZIP 文件名排序。

PDF 优先提取文本并核对阅读顺序；扫描件可用已有 OCR 工具，遇到古文、双栏、夹注、表格或数字须查看对应图像。OCR 结果标识状态，无法辨认处留缺字或疑读，不能悄悄猜字。DOCX、HTML、TXT、Markdown 保留标题、段落、注释与表格结构。加密或损坏时登记可读范围和阻碍。

## 原文文件

每个实际阅读单元在 `原文/` 保存一份主要 Markdown 提取文本。正文按原自然段；段落过长时按完整语义细分并登记规则，不用机械字数切断句子。诗歌、奏议、诏令和表保留层次。无可靠边界时记录真实合排范围，不凭目录填原文。

推荐使用稳定标题锚点，兼容普通 Markdown 和 Obsidian：

```markdown
# 原书篇名

来源：书名、版本；实际源文件／内部路径及原锚点。
定位说明：P 编号是本版提取段号，不是纸书页码。

## P0001

实际提取的正文。

## N0001

〔注释：标明注者及所引文献〕实际提取的注释。
```

示意内容不复制到真实档案。正文和注释用各自编号；附在 P 段后的注释记录对应关系，引用 N 段时注明层次。表格保留列标题、单位和注释，必要时给行组定位，不改写成虚假的自然段。原文页链接回实际笔记和首页。

编号与路径建立后保持稳定。新发现的遗漏用未使用编号并放在正确文本位置，不批量重编号；需要重新分段时保留旧版映射、更新入站链接并登记修订。版本不同的段号不能直接互换。OCR 校改保留重要修改记录，不将现代改写塞进原文层。

## 来源登记

在 `来源与进度.md` 维护书籍与外部文献编号、作者／编者、版本、文件位置或 URL、实际来源范围、正文／注释层次，以及单元到源路径的映射。页码说明是印刷页码还是 PDF 页序；未知项留未知。

篇卷清单分别记录：可用、已提取、已精读段落范围、已专题汇总、待核查、下一续接位置。覆盖状态不能互相替代。原文提取完成仍可能尚未精读。

## 引用与链接

普通 Markdown 用相对路径，例如笔记页 `[P0001](../原文/实际篇名.md#p0001)`；路径含空格用合法编码或尖括号目标。Obsidian 明确仓库位置后可用路径限定双链与标题定位，沿用现有结构，不强制迁移格式。

每条重要事实链接真正支持它的段落，必要时跨多个段落。引用加短摘录或检索词便于辨认，摘录逐字核对；不得只取人名第一次出现处充当事件依据。正文与注释的不同说法各自链接。

本地全文保留在用户档案；跨来源问答对外部书籍保留必要摘录和定位，不擅自把用户原书上传至发布仓库或外部服务。学术论文和网络材料须实际访问或由用户提供后才能声称已核实。
